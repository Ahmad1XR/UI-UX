# SmartBank — Mobile Banking UI/UX Case Study

SmartBank is a personal mobile banking UI/UX concept designed in Figma.

The project focuses on creating a simple, clear, and intuitive experience for everyday banking tasks, with complete user flows and an interactive prototype.

## Project Goals

- Create a clear and simple mobile banking experience
- Design complete end-to-end user flows
- Maintain visual consistency across screens
- Provide clear confirmation and feedback for financial actions

## Key Features

- Money transfer flow
- Bill payment flow
- Card management
- Card limits
- Transaction history
- Transaction details
- Notifications
- Account settings
- Interactive prototype

## Main User Flows

### Money Transfer

Transfer Money → Review Transfer → Transfer Successful

### Bill Payment

Pay Bills → Review Bill → Bill Payment Successful

## Design Highlights

- Review screens before confirming financial actions
- Clear selected states and feedback
- Readable transaction information
- Consistent navigation and visual identity
- Success states for completed actions
- Unread notification indicators

## Tools

- Figma
- Auto Layout
- Interactive Prototyping
- User Flows
- Mobile UI Design
